# 每日名言（Daily Quotes）详细设计文档

## 1. 项目概述

「每日名言」系统负责**每日从互联网采集 100 条名人名言**，按**知名度（popularity）**与**出处（source）**两个维度进行展示（前端典藏默认按知名度降序、每页 20 条），并允许运营人员通过页面**维护**（新增 / 编辑 / 删除）名言内容。

系统采用前后端分离架构：

- **后端**：Java 17 + Spring Boot 2.7，ORM 使用 **MyBatis-Plus**，支持 **MySQL / PostgreSQL / H2** 三种数据库。
- **前端**：Vue 3 + Vite，编辑风（editorial）视觉系统，响应式布局。

## 2. 技术栈

| 层次 | 技术选型 |
|------|----------|

| 前端 | Vue 3 + Vite + lucide-vue-next |

### 3.1 核心流程

1. **每日自动采集**：`QuoteFetchScheduler` 在 06:30 调用 `QuoteFetchService.fetchNow("SCHEDULED")`。
2. **去重与限量**：⚠️ 日限额**仅约束定时任务（SCHEDULED）**——仅当 `quote_fetch_log` 当日已存在 `SUCCESS` 记录时才跳过；**手动「立即采集」（MANUAL）不受日限额约束，可随时重新采集补充**（重复由指纹唯一索引兜底，不会写入重复数据）。随后循环调用互联网接口，用 `SHA-256(内容||作者)` 指纹做跨库去重。
   **重复即重采**：凡命中「本次批次指纹」或「历史库已有指纹」的条目一律跳过，并继续拉取新一批名言补充，直至凑满当日 10 条配额或达到最大尝试次数（`MAX_ATTEMPTS=10`）；每次按预估重复率多拉一批（`FETCH_PAGE_FACTOR=3`）以减少空转。写入阶段若仍发生唯一键冲突（`DataIntegrityViolationException`），按重复跳过并计入跳过数。
3. **持久化**：写入 `quote`（origin=INTERNET），并写入一条 `quote_fetch_log`（status=SUCCESS / FAILED）。
4. **展示**：前端分页查询 `quote`，支持关键词搜索、按出处筛选、按知名度/出处/作者/时间排序。
5. **维护**：运营通过弹窗新增 / 编辑 / 删除，后端在写入前再次按指纹去重校验。

### 3.2 多数据库适配

通过 Spring Profile 切换数据源，配置位于 `application.yml`：

| Profile | 数据库 | 连接信息 | 建表策略 |
|---------|--------|----------|----------|
| `h2`    | H2 文件库（本地零依赖） | `./data/daily-quotes` | 启动时执行 `schema-h2.sql` |
| `mysql` | MySQL 8（**默认数据源**） | `127.0.0.1:3306/daily_quotes` | 启动时执行 `schema-mysql.sql`（`continue-on-error` 幂等） |
| `pgsql` | PostgreSQL | `localhost:5432/daily_quotes` | 启动时执行 `schema-postgres.sql` |

默认已激活 `mysql` profile，直接启动即可；如需回退本地内置库：

```bash
java -Dfile.encoding=UTF-8 -jar daily-quotes-backend-1.0.0.jar --spring.profiles.active=h2
```

MySQL 实际连接串：

```yaml
url: jdbc:mysql://127.0.0.1:3306/daily_quotes?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true&rewriteBatchedStatements=true
username: root
```

> 切换数据库仅需修改连接信息并选择 profile，业务代码无需改动（MyBatis-Plus 自动识别方言）。MySQL 环境下需确保 `culture_daily` 库已创建，应用启动时会自动建表。

### 3.3 日志设计

- `logback-spring.xml` 配置 **CONSOLE** 与 **FILE** 两个 Appender，文件输出至 `logs/daily-quotes.log`（按天滚动，保留 30 天，UTF-8）。
- 开启 MyBatis-Plus 的 SQL 日志（`mybatis-plus.configuration.log-impl=StdOutImpl`），所有执行的 SQL 同时落到控制台与文件。
- 业务层使用统一前缀日志便于检索：`[DB查询]`、`[DB新增]`、`[DB更新]`、`[DB删除]`、`[DB统计]`、`[DB采集]`、`[DB初始化]`。

### 3.4 关键设计点

- **指纹去重**：`Quote.fingerprintOf()` 对「内容 + 作者」计算 SHA-256，数据库对 `fingerprint` 建唯一索引，从应用层与存储层双重避免重复。
- **每日限量**：`quote_fetch_log` 以 `fetch_date` 唯一维度（业务层按日计数）保证「每天最多新增 10 条互联网名言」。
- **自动填充**：`MyMetaObjectHandler` 在插入/更新时自动维护 `created_at`、`updated_at`；互联网来源自动写入 `last_fetched_date`。
- **逻辑删除**：MyBatis-Plus 已配置 `logic-delete-field: deleted`（当前实体未启用，便于后续扩展软删除）。
