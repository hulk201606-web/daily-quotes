# 每日名言（Daily Quotes）数据库设计文档

## 1. 概述

系统使用关系型数据库持久化名言数据与采集记录，支持 **MySQL 8 / PostgreSQL 12+ / H2** 三种数据库，通过 MyBatis-Plus 屏蔽方言差异。建表脚本位于 `backend/src/main/resources/`：

- `schema-h2.sql` —— H2（本地零依赖启动，应用启动时自动执行）
- `schema-mysql.sql` —— MySQL（**默认数据源**，应用启动时自动执行建表）
- `schema-postgres.sql` —— PostgreSQL

> 当前默认 profile 为 `mysql`：应用启动时通过 `spring.sql.init` 自动执行 `schema-mysql.sql`（`IF NOT EXISTS` 幂等建表），无需 DBA 手动执行。脚本含 `continue-on-error: true`，重复启动不会报错。如需切换，使用 `--spring.profiles.active=h2`（或 `pgsql`）。

## 1.1 MySQL 连接配置

`application.yml` 中 `mysql` profile 的实际连接信息（生产/联调环境按此对接）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/daily_quotes?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true&rewriteBatchedStatements=true
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: ********   # 见运维配置，实际为 ***REMOVED***
  sql:
    init:
      mode: always
      schema-locations: classpath:schema-mysql.sql
      continue-on-error: true
```

> 前置要求：目标库 `daily_quotes` 需已存在（建表脚本仅建表、不建库）。可在 MySQL 中执行 `CREATE DATABASE IF NOT EXISTS daily_quotes DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;` 后启动应用。

## 2. 实体关系

```
┌──────────────┐       ┌──────────────────────┐       ┌──────────────────────────┐
│   sys_user   │       │        quote         │       │     quote_fetch_log      │
│  (用户/权限) │       │  (名言主表)          │       │  (每日采集执行记录)       │
├──────────────┤       ├──────────────────────┤       ├──────────────────────────┤
│ id  (PK)     │1     N│ id  (PK, 自增)       │       │ id (PK, 自增)             │
│ username (UK)│──┐    │ content              │       │ fetch_date (业务日期)     │
│ role         │  │    │ ...                  │       │ fetch_type (SCHEDULED/..) │
│ display_name │  │    │ ...                  │       │ ...                      │
└──────────────┘  │    └──────────────────────┘       └──────────────────────────┘
                 │              ▲
                 │              │ user_quote_tag.user_id / quote_id / tag_id
                 │              │
        ┌────────┴──────────────┴──────────┐
        │          user_quote_tag           │  名言-个人标签关联（归类收录）
        ├──────────────────────────────────┤
        │ user_id (FK→sys_user)             │
        │ quote_id (FK→quote)               │
        │ tag_id  (FK→user_tag)             │
        └──────────────────────────────────┘
        ┌──────────────────────┐       ┌──────────────────────────┐
        │     user_tag         │       │    user_favorite         │
        │ (个人标签字典)        │       │  (个人收藏/喜好收录)      │
        ├──────────────────────┤       ├──────────────────────────┤
        │ id (PK)              │       │ user_id (FK→sys_user)    │
        │ user_id (FK)         │       │ quote_id (FK→quote)      │
        │ name (user内唯一)     │       └──────────────────────────┘
        └──────────────────────┘
```

新增的四张个人化/权限表（`sys_user`、`user_tag`、`user_favorite`、`user_quote_tag`）均以 `user_id` 为隔离边界，保证不同用户之间的标签与收藏互不干扰；其中 `user_quote_tag` 通过 `quote_id` 关联到公共名言主表 `quote`，实现「按个人标签归类收录」。`quote_fetch_log` 与业务主表相互独立，仅记录采集任务的执行结果。

## 3. 数据表设计

### 3.1 quote（名言主表）

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / BIGINT AUTO_INCREMENT / BIGSERIAL | 是 | 主键 |
| content | VARCHAR(2000) | 是 | 名言内容 |
| author | VARCHAR(120) | 是 | 作者 |
| source | VARCHAR(180) | 是 | 出处 |
| popularity | INT | 是 | 知名度（1-100），用于排序与展示 |
| featured | BIT / TINYINT(1) / SMALLINT | 是 | 是否精选（0/1） |
| origin | VARCHAR(20) | 是 | 来源：`SEED` / `INTERNET` / `MANUAL` |
| fingerprint | VARCHAR(64) | 是 | 内容+作者 的 SHA-256，唯一约束 |
| last_fetched_date | DATE（可空） | 否 | 互联网采集日期（按天去重/限量） |
| created_at | TIMESTAMP | 是 | 创建时间（自动填充） |
| updated_at | TIMESTAMP | 是 | 更新时间（自动填充） |

**约束与索引**

- `UK_QUOTE_FINGERPRINT (fingerprint)` —— 唯一索引，保证名言不重复。
- `idx_quote_popularity` —— 按知名度排序加速。
- `idx_quote_origin` —— 按来源统计加速。
- `idx_quote_source` —— 按出处筛选加速。

### 3.2 quote_fetch_log（采集日志表）

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / BIGINT AUTO_INCREMENT / BIGSERIAL | 是 | 主键 |
| fetch_date | DATE | 是 | 业务日期（每日一条） |
| fetch_type | VARCHAR(20) | 是 | 触发方式：`SCHEDULED`（定时）/ `MANUAL`（手动） |
| fetched_count | INT | 是 | 本次成功写入条数 |
| skipped_count | INT | 是 | 因重复跳过条数 |
| total_attempts | INT | 是 | 采集尝试次数 |
| status | VARCHAR(20) | 是 | `SUCCESS` / `FAILED` |
| error_message | VARCHAR(1000) | 否 | 失败原因 |
| created_at | TIMESTAMP | 是 | 记录时间 |

**索引**：`idx_fetch_log_date (fetch_date)`。

### 3.3 sys_user（用户表）

支撑「个人标签 / 喜好收录」与「角色权限控制」的最小用户模型。

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / AUTO_INCREMENT / BIGSERIAL | 是 | 主键（种子数据固定为 1=admin、2=zhangsan、3=lisi，便于联调） |
| username | VARCHAR(64) | 是 | 登录名，唯一 |
| display_name | VARCHAR(120) | 是 | 展示名（如「管理员」「张三」） |
| role | VARCHAR(20) | 是 | 角色：`ADMIN` / `USER` |
| created_at | TIMESTAMP | 是 | 创建时间（自动填充） |

**约束与索引**：`UK_SYS_USER_USERNAME (username)` 唯一索引。

### 3.4 user_tag（个人标签字典）

每名用户独立的标签字典（如「治愈」「励志」），标签名在「同一用户」范围内唯一。

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / AUTO_INCREMENT / BIGSERIAL | 是 | 主键 |
| user_id | BIGINT | 是 | 所属用户（FK→sys_user） |
| name | VARCHAR(64) | 是 | 标签名 |
| created_at | TIMESTAMP | 是 | 创建时间（自动填充） |

**约束与索引**：`UK_USER_TAG (user_id, name)` 唯一索引；`idx_user_tag_user (user_id)`。

### 3.5 user_favorite（个人收藏 / 喜好收录）

用户对名言的收藏关系，同一用户对同一名言至多收藏一次。

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / AUTO_INCREMENT / BIGSERIAL | 是 | 主键 |
| user_id | BIGINT | 是 | 收藏者（FK→sys_user） |
| quote_id | BIGINT | 是 | 被收藏名言（FK→quote） |
| created_at | TIMESTAMP | 是 | 创建时间（自动填充） |

**约束与索引**：`UK_USER_FAVORITE (user_id, quote_id)` 唯一索引；`idx_user_favorite_user`、`idx_user_favorite_quote`。

### 3.6 user_quote_tag（名言-个人标签关联）

将个人标签贴到具体名言上，实现「按个人标签归类收录」。

| 字段名 | 类型（H2/MySQL/PG） | 必填 | 说明 |
|--------|----------------------|------|------|
| id | BIGINT AUTO_INCREMENT / AUTO_INCREMENT / BIGSERIAL | 是 | 主键 |
| user_id | BIGINT | 是 | 所属用户（FK→sys_user） |
| quote_id | BIGINT | 是 | 关联名言（FK→quote） |
| tag_id | BIGINT | 是 | 关联标签（FK→user_tag） |
| created_at | TIMESTAMP | 是 | 创建时间（自动填充） |

**约束与索引**：`UK_USER_QUOTE_TAG (user_id, quote_id, tag_id)` 唯一索引；`idx_user_quote_tag_user`、`idx_user_quote_tag_quote`。

> 删除个人标签（`DELETE /api/personal/tags/{tagId}`）时会级联清理 `user_quote_tag` 中的对应关联，避免孤儿数据。

## 4. 跨数据库兼容性说明

| 能力 | H2 | MySQL | PostgreSQL |
|------|----|-------|------------|
| 主键自增 | `AUTO_INCREMENT` | `AUTO_INCREMENT` | `BIGSERIAL` / `GENERATED BY DEFAULT AS IDENTITY` |
| 布尔 | `BIT` | `TINYINT(1)` | `SMALLINT` / `BOOLEAN` |
| 文本 | `VARCHAR` | `VARCHAR` + `utf8mb4` | `VARCHAR` |
| 时间 | `TIMESTAMP` | `DATETIME(6)` | `TIMESTAMP(6)` |
| 唯一约束 | 支持 | 支持 | 支持 |

应用层统一使用 MyBatis-Plus 的 `IdType.AUTO`，由底层数据库提供自增能力；布尔字段在实体中以 `Boolean` 表示，框架自动完成类型映射。

## 5. H2 建表脚本（节选）

```sql
CREATE TABLE quote (
    id               BIGINT AUTO_INCREMENT PRIMARY KEY,
    content          VARCHAR(2000) NOT NULL,
    author           VARCHAR(120)  NOT NULL,
    source           VARCHAR(180)  NOT NULL,
    popularity       INT           NOT NULL,
    featured         BIT           NOT NULL DEFAULT 0,
    origin           VARCHAR(20)   NOT NULL,
    fingerprint      VARCHAR(64)   NOT NULL,
    last_fetched_date DATE         NULL,
    created_at       TIMESTAMP     NOT NULL,
    updated_at       TIMESTAMP     NOT NULL,
    CONSTRAINT uk_quote_fingerprint UNIQUE (fingerprint)
);
```

> MySQL / PostgreSQL 版本见 `schema-mysql.sql` 与 `schema-postgres.sql`，主要差异集中在自增主键、布尔与时间类型的方言写法。
